評価のしかた

道具は SRC/exec/mlo_bandcheck.py。対称線の上の同じ k 点で、DFT のバンドと MLO のバンドを E_F 基準の eV で比べる。

金属か絶縁体か
SCF の k メッシュ（efermi.lmf）で E_F が価電子帯の頂上にありギャップが 0.05 eV より大きく、対称線の上でもギャップが 0.05 eV より大きいときだけ絶縁体。
ギャップ
表 1 のギャップは DFT の、k メッシュと対称線の上のうち小さい方。ギャップの誤差は対称線の上の MLO − DFT。
誤差を見る窓
VBM − 8 eV 〜 CBM + mlo_delta（どの物質も 2 eV。金属は E_F − 8 〜 E_F + 2 eV）。mlo_delta は模型を合わせる範囲の上端 （CBM からどこまで上を合わせるか）なので、同じ範囲で評価する。この中で、DFT の帯が模型にあるか（DFT → MLO）と、模型の帯が DFT にあるか（MLO → DFT）の両方を見る。図では窓を斜線で示す。 （2026-10-01 17:54 まで、上端は DFT → MLO が CBM + 1、MLO → DFT が CBM + 3 eV だった）
誤差の最大値
窓の中の各点について同じ k で最も近い相手の帯との差をとり、その rms を 2 つの向きで出す。誤差の最大値 = max（rms MLO → DFT、rms DFT → MLO、|ギャップの誤差|）。 判定は good ≤ 0.02、fair ≤ 0.05、marginal ≤ 0.1、poor > 0.1 eV。

模型の作り方

@@COUNTS@@
EH
PMT の基底の第 1 の smooth Hankel 関数。どの模型も mlo_lm の (原子, lm) ごとに 1 本持つ（s,p,d。4f の原子は f も）。
1. 基準
入力には何も書かない。半内殻の帯は、同じ種類の原子の局所軌道をまとめた部分空間への重みが 1/2 を超える占有状態で見る （La₂CuO₄ の La 5p は 2 つの La に半分ずつ広がる）。Ga 3d・In 4d・Eu 5p・La 5p・Sr 4p が O・N の 2p と混ざる系が直る。
2. 陽イオンに EH2
空隙の大きい閃亜鉛鉱・wurtzite の化合物（MgX・CdTe・ZnTe・AlN など）で、隙間に広がった伝導帯の底を表す。 単体の金属では全原子が対象になり、Cu・Ni は壊れる。EuO は模型を作る所で止まった（PMT の完全性の損失が大きすぎる）ので 64 物質。
3. 空格子球
いまは SiO₂ クリストバライトだけ: Si のダイヤモンド網の空隙 2 か所（立方体の単位で ½(111) と ¾(111)）に r = 2.6 a.u. の球（図 4 の先頭）。
