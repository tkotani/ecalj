# AGENTS.md — entry point for AI coding agents

This file is for AI agents other than Claude Code (which reads `CLAUDE.md`). Both lead to the same documents.

1. Read [`CLAUDE.md`](CLAUDE.md): the licence terms for AI work (ecalj is AGPLv3) and the entry to the developer documents.
2. The map of the developer documents is the first section of [`MD/ecaljclaude.md`](MD/ecaljclaude.md) (in Japanese): coding rules
   (Fortran modules as singletons), how to keep records, build and test, GPU lessons.
3. Facts checked in the code and the samples, and the steps to edit the documentation site: [`MD/ecalj_knowledge.md`](MD/ecalj_knowledge.md)
   (written for AI, not for humans).
4. The user documentation is the site source [`ecaljdoc/`](ecaljdoc/) (Japanese pages are the reference; English twins in `ecaljdoc/en/`),
   published at https://ecalj.github.io/ecaljdoc/. Its writing rules: [`ecaljdoc/manual/writing_docs.md`](ecaljdoc/manual/writing_docs.md).

License: ecalj is AGPLv3. AI is no exception — the terms bind an AI agent's work as they would a person's. Follow
[`ecaljdoc/manual/license.md`](ecaljdoc/manual/license.md); if a request would cross one of its lines, raise it with the person instead of proceeding.
