評価のしかた

道具は SRC/exec/mlo_bandcheck.py。対称線の上の同じ k 点で、DFT のバンド（job_band の bnd*）と MLO のバンド（band_MLO_spin*.dat）を、 どちらも E_F 基準の eV で比べる（BZ 全体ではなく対称線の上だけ）。

金属か絶縁体か
次の両方を満たしたときだけ絶縁体。(i) SCF の k メッシュ（efermi.lmf）で E_F が価電子帯の頂上にあり、メッシュのギャップが 0.05 eV より大きい。 (ii) 対称線の上の DFT の CBM − VBM が 0.05 eV より大きい。
ギャップ
メッシュのギャップ（gap_mesh）と、対称線の上の DFT のギャップ（gapD）を両方出す。VBM と CBM の区切りはメッシュのギャップの中央 （メッシュが粗いと線の上の VBM がメッシュの E_F より上に出るため）。MLO と比べるのは線の上どうし: gapM は DFT の線の上のギャップの中央より下の最高点と上の最低点の差。 ギャップの差 = gapM − gapD。
rms MLO → DFT
[VBM − 8, CBM + 3] eV にある MLO の各点について、同じ k で最も近い DFT のバンドとの差の rms（余計な帯・外れた帯が出る）。最大のずれも表に出す。
rms DFT → MLO
[VBM − 8, CBM + 1] eV にある DFT の各点について、同じ k で最も近い MLO のバンドとの差の rms（模型から抜けた帯が出る）。
金属
VBM = CBM = E_F として同じ窓。
最悪値と判定
最悪値 = max（rms MLO → DFT、rms DFT → MLO、|ギャップの差|）。判定に使うのは rms で、1 点ごとの最大のずれは入れていない （帯の一部だけ大きく外れても rms が小さければ good・fair になりうる。表の max の列で確かめる）。good ≤ 0.02、fair ≤ 0.05、marginal ≤ 0.1、poor > 0.1 eV。
限界
「最も近い帯」で対応づけるので、帯の密なところでは別の帯と組になって誤差を小さく見積もりうる。窓の上は CBM + 3 eV まで（模型の合わせる範囲 mlo_delta = 2 eV とその上の減衰を少し超えるところ）。有効質量は見ていない。

模型の作り方（4 つ）

  1. 旧既定（2026-10-01 14:4x まで）: mlo_lm の (原子, lm) ごとに動径関数を 1 本（PMT の基底の第 1 の smooth Hankel 関数、EH）。 半内殻の局所軌道は、帯の上端が E_F − 10 eV より上なら EH と入れ替え、下は外す。表 1 の「旧既定」の列。
  2. 基準: 半内殻の局所軌道を自動で入れる（m_HamPMT の変更、入力には何も書かない）。帯の上端が E_F − 17 eV より上の半内殻の局所軌道を、EH の関数に 加えて模型の関数にする。帯は「同じ種類の原子の局所軌道をまとめた部分空間への重みが 1/2 を超える占有状態」で見る（La₂CuO₄ の La 5p は 2 つの La に半分ずつ広がり、 1 原子ずつでは見つからなかった）。Ga 3d・In 4d・Eu 5p・La 5p・Sr 4p が O・N の 2p と混ざる系が直る。
  3. 陽イオンに EH2 の s,p（手で mlo_lm2 に書く）: 陽イオン（N・O・F・P・S・Cl・As・Se・Br・Sb・Te・I 以外の原子）の s,p に第 2 の smooth Hankel 関数を加える。 空隙の大きい閃亜鉛鉱・wurtzite の化合物で、隙間に広がった伝導帯の底を表す。単体の金属などでは全原子が対象になり、壊れることがある（Cu）。
  4. 空格子球（手で [[site]]・[[spec]] に置く。DFT から回し直す）: 空隙に z = 0 の球を置き、その s,p を模型に入れる。いまは SiO₂ クリストバライトだけ （Si のダイヤモンド網の空隙、立方体の単位で ½(111) と ¾(111)、r = 2.6 a.u.）。
